# Пестринин Даниил ИТ-17 Лабораторная №3

## Задание 1. Инкапсуляция

### Задача 1.6. Отдельные линии

Текст задачи: Изменить сущность Линия так, чтобы две любые линии не могли ссылаться на один и тот же объект точки. У линии можно изменять и запрашивать координаты начала и конца.

Алгоритм решения: В конструкторе и сеттеры переданные точки копируются с помощью метода `clone()`. Геттеры также возвращают копии точек. Благодаря этому внешние изменения объектов точек не изменяют состояние линии. Пример демонстрирует создание линии по двум точкам, изменение внешней точки и последующее изменение начала самой линии через сеттер.

### Задача 1.12. Квадрат

Текст задачи: Создать сущность Квадрат, которая хранит точку левого верхнего угла и длину стороны. Квадрат создается по точке или по координатам. Квадрат приводится к строке вида «Квадрат в точке T со стороной N» и может возвращать ломаную из точек своих углов.

Алгоритм решения: Класс `Square` хранит поле `topLeft` типа `Point` и целое поле `side`. Для обоих способов создания предусмотрены отдельные конструкторы. Метод `getPolygonalChain()` вычисляет три других угла квадрата и передает их в конструктор `PolygonalChain`. В демонстрации создается квадрат в точке `{5;3}` со стороной 23, определяется длина его ломаной, после чего последняя точка ломаной заменяется на `{15;25}` и длина вычисляется снова.

## Задание 2. Разработка структур данных

### Задача 2.1. Неизменяемый массив

Текст задачи: Разработать сущность `ImmutableIntList`, которая хранит массив целых чисел и поддерживает создание по массиву, перечню независимых значений и другому списку. Необходимо получить значение по индексу, заменить значение с созданием нового списка, преобразовать список в строку, проверить пустоту и размер и получить копию массива.

Алгоритм решения: Внутренний массив объявлен как `private final int[] data`, а переданное извне значение копируется в конструкторе. Перегруженные конструкторы поддерживают передачу массива и копирование другого списка. Метод `get()` проверяет границы индекса и возвращает значение. Метод `set()` проверяет индекс, копирует массив и создаст новый объект с измененным значением, поэтому исходный список не меняется. Методы `isEmpty()`, `size()` и `toArray()` предоставляют запрошенное состояние и защитную копию массива.

## Задание 3. Наследование

### Задача 3.5. Трехмерная точка

Текст задачи: Создать подвид точки с координатами X, Y и Z.

Алгоритм решения: Класс `Point3D` наследуется от класса `Point` с помощью ключевого слова `extends`. Конструктор производного класса передает координаты X и Y базовому конструктору через `super()`. Для координаты Z реализованы геттер и сеттер. Методы `equals()`, `hashCode()` и `toString()` переопределены так, чтобы учитывать три координаты. Для клонирования переопределен метод `clone()`.

## Задание 4. Создание иерархий

### Задача 4.5. Точки с характеристиками

Текст задачи: Разработать сущности точек с разными характеристиками, включая координаты, цвет и время появления. Характеристики могут применяться отдельно или в различных комбинациях, а двухмерная и трехмерная точки должны оставаться доступными для последующего использования.

Алгоритм решения: Абстрактный базовый класс `AbstractCoordinatePoint` определяет общие характеристики точек и абстрактный метод получения описания. Класс `Point1D` хранит одну координату X. Класс `ColoredPoint` наследует двухмерную точку и добавляет цвет. Класс `TimedPoint3D` наследует трехмерную точку и добавляет время. Класс `ColoredTimedPoint` демонстрирует комбинацию координат X и Y, времени появления и цвета. Для каждого класса реализованы свойства, конструкторы и `toString()`.

## Задание 5. Полиморфизм

### Задача 5.1. Сложение чисел

Текст задачи: Разработать метод, принимающий набор числовых значений и возвращающий их сумму в вещественной форме. С помощью метода выполнить сложения `2 + 3/5 + 2.3`, `3.6 + 49/12 + 3 + 3/2` и `1/3 + 1`.

Алгоритм решения: В классе `MathUtils` метод `sum()` принимает переменное число аргументов типа `Object...`. Для каждого аргумента проверяется, реализует ли объект интерфейсные возможности `Number`, после чего вызывается `doubleValue()`. Дробь представлена классом `Fraction`, наследующим `Number`, поэтому она преобразуется к вещественному значению одинаково с целыми и вещественными числами.

## Задание 6. Полиморфное сравнение

### Сравнение линий

Текст задачи: Переопределить сравнение линий так, чтобы две линии считались одинаковыми при совпадении их начальных и конечных точек.

Алгоритм решения: В классе `Line` метод `equals()` сначала проверяет ссылку и класс объекта, затем сравнивает поля начала и конца через метод `equals()` класса `Point`. Для согласованности переопределен метод `hashCode()`. Таким образом две линии считаются равными, если координаты обеих пар точек совпадают.

## Задание 7. Пакеты

### Задача 7.1. Навести порядок

Текст задачи: Распределить ранее написанные классы по логически связанным пакетам с трехсоставными именами вида `ru.surname.type`.

Алгоритм решения: Классы геометрических объектов расположены в пакете `ru.crismer.geometry`, дроби — в `ru.crismer.math`, неизменяемый список — в `ru.crismer.structures`, вспомогательные методы — в `ru.crismer.utils`. Это отделяет логические группы и упрощает повторное использование классов.

### Задача 7.2. Главный метод

Текст задачи: Создать пакет `ru.surname.main` с классом, содержащим точку входа `public static void main`. Ни в одном другом пакете точка входа отсутствует.

Алгоритм решения: Класс `Main` расположен в пакете `ru.crismer.main`. В нем реализовано консольное меню с клавиатурным вводом и вызовами методов всех изученных сущностей. В остальных пакетах классов с точкой входа нет.

### Задача 7.3. Возведение в степень

Текст задачи: Создать метод, который принимает две строки X и Y и возвращает результат возведения X в степень Y. Для преобразования строк использовать `Integer.parseInt`, а для возведения использовать `Math.pow`. Метод вызывается с параметрами командной строки.

Алгоритм решения: В классе `Main` метод `raiseToPower(String base, String exponent)` преобразует обе строки с помощью статического метода `parseInt`, а затем вызывает статический метод `pow`. В классе используются статические короткие имена импортов для `parseInt` и `pow`. Если аргументы командной строки переданы, они используются в методе; иначе основание и показатель запрашиваются с клавиатуры.

## Задание 8. Пакетная инкапсуляция

### Клонирование линии

Текст задачи: Переопределить метод клонирования линии так, чтобы при клонировании создавался новый объект с копиями всех точек оригинала.

Алгоритм решения: В классе `Line` переопределен метод `clone()`. Сначала вызывается `super.clone()`, затем поля начала и конца заменяются независимыми клонами соответствующих точек. Исключение `CloneNotSupportedException` обработано внутри метода как невозможная ситуация. В результате изменение клонированной линии не влияет на исходный объект.
java -cp out ru.crismer.main.Main 2 10
